Scheduling ds_load with a DAG mutation

A talk given to the maintainers of AMD's CoExecScheduler, arguing that ds_load bunching on gfx1250 WMMA GEMMs is a relational constraint — each load belongs inside a window defined by the WMMAs that consume it — and so belongs in a DAG mutation rather than in the scheduler's pairwise comparator.

Every frame is generated from source at build time: the animations are manim scenes, the charts are matplotlib, and both read ~76 KB of JSON distilled from the scheduler's own debug output. Nothing in the deck is drawn by hand, and no video is stored in this repository.

Arrow keys move between slides; F is fullscreen and Esc shows the overview. If the embed is cramped, open the deck on its own.
