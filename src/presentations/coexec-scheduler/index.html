Scheduling ds_load with a DAG mutation

A talk given to the maintainers of AMD's CoExecScheduler, arguing that ds_load bunching on gfx1250 WMMA GEMMs is a relational constraint — each load belongs inside a window defined by the WMMAs that consume it — and so belongs in a DAG mutation rather than in the scheduler's pairwise comparator. Every figure is generated from the scheduler's own debug output; nothing here is hand-drawn.
